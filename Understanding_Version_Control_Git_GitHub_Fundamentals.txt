Assignment Title Understanding Version Control, Git, and GitHub
Fundamentals

1.  What is Version Control and Why is it Important?

Version control is a system that records changes made to files over
time. It allows developers to track modifications, restore previous
versions, and collaborate efficiently. It is important because it
prevents data loss, keeps a history of changes, and enables multiple
developers to work on the same project without overwriting each other’s
work.

2.  Why Do Developers Use Git?

Git is a distributed version control system used to manage source code.
Developers use Git to: - Track code changes. - Work on features without
affecting the main project. - Collaborate with team members. - Restore
previous versions if needed. - Maintain a complete history of the
project.

3.  Common Problems Git Solves

-   Prevents accidental loss of code.
-   Keeps track of every change.
-   Allows multiple developers to work simultaneously.
-   Makes it easy to merge changes.
-   Helps identify who made changes and when.
-   Allows reverting to a previous stable version.

4.  Difference Between Git and GitHub

Git: - Local version control system. - Tracks and manages source code. -
Works offline.

GitHub: - Cloud platform for hosting Git repositories. - Enables
collaboration, pull requests, and code sharing. - Uses Git repositories.

5.  Centralized vs Distributed Version Control

Centralized Version Control (CVCS): - One central server stores the
project. - Requires server access. - Server failure can affect the team.

Distributed Version Control (DVCS): - Every developer has a complete
repository copy. - Supports offline work. - Better reliability and
collaboration. - Git is a DVCS.

Conclusion

Git and GitHub make software development easier by tracking changes,
enabling collaboration, and maintaining complete project history.
